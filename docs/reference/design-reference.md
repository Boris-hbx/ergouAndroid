# 二狗 App 设计参考文档

> 基于豆包（字节跳动）和小艺（华为）两款主流 AI 助手 App 的调研，为二狗 App 提供设计参考方案。

---

## 一、竞品分析

### 1.1 豆包 (Doubao) — 字节跳动

#### 导航结构
- **底部三 Tab**：首页 / 发现 / 我的
- 设计极简，三个入口覆盖所有功能

#### 首页布局
```
┌─────────────────────────┐
│  顶部: 搜索栏 / 通知     │
├─────────────────────────┤
│  欢迎语 + 个性化问候      │
├─────────────────────────┤
│  快捷功能卡片 (横向滚动)   │
│  [AI搜索] [写作] [生图]   │
│  [阅读总结] [音乐] [更多]  │
├─────────────────────────┤
│  热门智能体入口            │
│  (圆形头像 + 名称网格)     │
├─────────────────────────┤
│  最近对话列表              │
├─────────────────────────┤
│  底部输入框               │
│  [附件] [截图] [语音] [发送]│
└─────────────────────────┘
```

#### 对话页面
- 气泡式对话 (用户右侧, AI 左侧)
- AI 回复下方操作栏：复制 / 重新生成 / 点赞 / 点踩
- 支持上传文件、图片、截图
- 流式输出，支持随时打断
- 对话中可切换智能体

#### 发现页面
- 智能体广场：分类浏览 + 搜索
- 热门推荐 / 排行榜
- 用户可创建自定义智能体（设定头像、昵称、描述、声音）

#### 我的页面
- 头像 / 昵称 / ID
- 最近对话 / 我的智能体 / 收藏夹
- 暗色模式切换
- 设置：个人资料、帮助反馈、黑名单、关于、账号设置、退出登录

#### 核心交互特点
- 快捷卡片替代手动输入（一键启动特定功能）
- 输入框统一设计，全局一致（文件+截图+语音+发送）
- 智能体系统贯穿全应用
- 无广告纯净体验
- AI 主动猜测用户后续问题，提供建议追问

### 1.2 小艺 (Celia) — 华为

#### 导航结构
- **顶部 Tab**：新对话 / 热门技能 / 深度研究 / 交互式学习 / 历史对话
- 系统级集成，非独立 Tab 结构

#### 首页布局
```
┌─────────────────────────┐
│  顶部: Tab 切换栏         │
├─────────────────────────┤
│  小艺形象 (真人感/动画)    │
├─────────────────────────┤
│  建议卡片 (基于场景感知)   │
│  [日程提醒] [天气] [待办]  │
│  [新闻摘要] [快捷支付]     │
├─────────────────────────┤
│  技能广场入口              │
│  列表型卡片 + 分类导航     │
│  动态Banner / 热门推荐     │
├─────────────────────────┤
│  底部输入区               │
│  [语音] [文字] [拍照]     │
└─────────────────────────┘
```

#### 对话交互
- 半屏态 / 全屏态两种唤醒模式
- 支持语音随时打断 AI 回答
- 16 种方言识别
- 11 种情绪感知，自适应回应语气
- 拖拽跨应用协作

#### 智能体与技能
- 健康顾问、文案写手、编程助手、翻译等
- 技能页面从双排卡片优化为列表卡片
- 灵感专题推荐

#### 系统级集成（二狗参考方向）
- **小艺简报**：早间推送个人专属日报（日程 + 待办 + 天气 + 新闻）
- **小艺建议**：桌面 Widget，根据时间/地点/习惯动态推荐服务
- **全局待办**：整合来自多个应用的待办事项
- **情景感知**：基于个人 AI 知识图谱的主动推荐

#### 隐私设计
- "不泄露、不存储、不滥用"原则
- 个人数据本地处理

## 三、二狗设计方案

### 3.1 架构决策：对话为核心，单屏设计

**不采用** 多 Tab 底部导航，**采用**以对话为唯一主界面的设计。
功能入口收敛到输入框上方的快捷标签条，所有操作都通过二狗对话完成或从快捷条跳转。

> 设计理念：二狗 = 主界面 = 沟通入口，用户和二狗说一切。

### 3.2 主界面布局

```
┌──────────────────────────────┐
│  二狗            [历史] [⚙️]  │  ← 顶栏(简洁)
├──────────────────────────────┤
│                              │
│  (对话消息流 — 全屏空间)       │
│                              │
│       ┌──────────────┐       │
│       │  用户消息      │      │
│       └──────────────┘       │
│  ┌───────────────────┐       │
│  │  二狗回复           │      │
│  │  (Markdown 渲染)    │      │
│  │  [复制] [重新生成]   │      │
│  └───────────────────┘       │
│                              │
├──────────────────────────────┤
│ [Todo]例行  [记账]差旅  ...   │  ← 快捷条(最近/常用条目)
├──────────────────────────────┤
│ [📎]  输入消息...       [➤]  │  ← 输入框(语音按钮暂不呈现)
└──────────────────────────────┘
```

#### 快捷条交互逻辑
- 快捷条显示**最近/常用的具体条目**，格式为 `[分类]内容`
- 例如：`[Todo]例行` `[记账]差旅` `[学习]英语` `[健康]跑步`
- 点击某个条目 → 跳转到对应功能的详情页面
- 点击输入框 → 始终回到二狗对话模式
- 快捷条可横向滚动，显示最常用的 4-5 个条目
- 条目根据使用频率和时间自动排序（最近用的排前面）

#### 设计要点
- 对话占据绝大部分屏幕空间，体验和豆包/小艺的对话页一致
- 快捷条只占一行高度（约40dp），不抢对话空间
- 新会话时，对话区可显示二狗有深度问候 + 建议话题

### 3.3 子页面（从快捷条跳转）

子页面统一结构：顶部返回箭头 → 点击回到对话主界面。

**Todo 页面**
```
┌──────────────────────────────┐
│  ← 返回    待办事项            │
│  [Today 4] [This Week] [30D]  │
├──────────────────────────────┤
│  □ 差旅审批、报销         🎯  │
│  □ proof of immunization  🔥  │
│  □ 快递                   🔥  │
│  □ 刘锦 快递              ⚡  │
├──────────────────────────────┤
│  已完成 (19) ▼                │
│                     [+ FAB]   │
└──────────────────────────────┘
```

**记账页面** / **例行页面** / **学习页面** — 同理，独立全屏，左上角返回。

### 3.4 对话体验优化

- **AI 回复操作栏**：复制 / 重新生成（参考豆包，用户习惯）
- **流式输出打断**：加停止按钮
- **新会话空态**：二狗头像 + 随机有深度问候 + 2-3 个建议话题卡片

### 3.5 设置页面（从顶栏⚙️进入）

```
┌──────────────────────────────┐
│  ← 返回    设置               │
├──────────────────────────────┤
│  🤖 AI 设置                  │
│     API Key / 模型            │
├──────────────────────────────┤
│  🎨 外观                     │
│     深色模式: [自动/浅/深]     │
├──────────────────────────────┤
│  🔔 通知与提醒               │
├──────────────────────────────┤
│  🛡️ 隐私与数据              │
│     数据全部本地 / 导出 / 清除 │
├──────────────────────────────┤
│  ℹ️ 关于二狗                 │
└──────────────────────────────┘
```

## 四、二狗差异化设计

二狗不是豆包/小艺的复制品，以下是核心差异点：

| 维度 | 豆包/小艺 | 二狗 |
|------|----------|------|
| **定位** | 通用 AI 助手 | 个人私密助手 |
| **性格** | 礼貌专业 | 有深度有知识的个人助手（有温度的吐槽） |
| **数据** | 云端存储 | 100% 本地，隐私优先 |
| **功能** | 大而全 | 聚焦个人管理（待办/记账/健康/学习） |
| **智能体** | 多角色切换 | 只有二狗一个角色（但了解你的一切） |
| **记忆** | 有限上下文 | 持久记忆系统，越用越懂你 |
| **主动性** | 被动响应为主 | 主动提醒、吐槽、关心 |

### 二狗独有特色
1. **有深度关心**："又熬夜？上次你说要早睡的，记性比金鱼还差？"
2. **记忆串联**："你上周说要减肥，今天又记了奶茶的账，要我说什么好？"
3. **个人数据洞察**："这个月花了 3000 多，比上个月多了 40%，主要是购物，管住手啊"
4. **隐私承诺**：所有数据本地存储，是真正的"只有你知道的朋友"
