# 养生（Health）功能设计文档

> 遵循 [功能页面通用设计规范](feature-screen-conventions.md)
> 注意：养生模块使用静态数据，无 API 调用，无需登录

## 现状

### UI
- Scaffold + TopAppBar("养生功法")
- ScrollableTabRow 四个分类：八段锦(8项) / 易筋经(12项) / 站桩(5项) / 经络穴位(14项)
- LazyColumn 展示 HealthItemCard：名称 + 描述 + 功效 + 经络 + 穴位
- 无 FAB（只读内容）
- 无登录门控

### 工具
- 无（之前的 LogHealthTool 和 HealthSummaryTool 已删除）

### 数据
- `HealthData` 静态对象：4 个类别，约 39 个条目
- 纯本地数据，不依赖 Next API

## 改进计划

### UI 改进

#### 1. 条目卡片优化
- 可折叠/展开设计：默认只显示名称和描述，点击展开详情（功效/经络/穴位）
- 减少信息过载，每个分类十几个条目全展开太长

#### 2. 搜索功能
- TopAppBar 右侧添加搜索按钮
- 支持按名称、功效、穴位名搜索
- 高亮匹配文字

#### 3. 收藏/常练标记
- 每个条目右上角收藏星标
- 收藏数据存 DataStore（本地偏好，不需要 API）
- 顶部增加"常练"筛选标签，只看收藏项

#### 4. 练习计时器
- 点击条目可启动练习模式
- 简单计时器界面：功法名称 + 倒计时/正计时 + 开始/暂停/完成
- 每个动作建议时长（八段锦每式 1-2 分钟，站桩 5-30 分钟）
- 练习完成后记录到本地（DataStore 或 Room）

#### 5. 分类描述
- 每个分类顶部添加简介卡片：简述该功法的来源、适用人群、注意事项
- 例如八段锦："源自宋代，8 个动作疏通经络，适合各年龄段"

#### 6. 穴位图示（预留）
- 经络穴位分类可扩展为图文展示
- 当前先用文字描述，未来可加示意图

### 工具改进

#### 7. 新增工具：`query_health`
- 参数：category（可选：baduanjin/yijinjing/zhuanzhuang/meridian），keyword（可选）
- 返回匹配的功法条目：名称 + 描述 + 功效
- 用途：二狗回答"八段锦第三式是什么"、"哪个动作对腰好"

#### 8. 新增工具：`recommend_health`
- 参数：symptom（症状描述，如"腰酸"、"失眠"、"肩颈僵硬"）
- 根据功效匹配推荐合适的功法
- 返回 2-3 个推荐条目及理由
- 用途：二狗据此建议："腰酸的话推荐八段锦第五式'摇头摆尾去心火'和站桩'混元桩'"

### 集成

#### 9. 快捷栏推送
- 养生不在默认快捷栏（通过功能广场进入）
- 如用户设有练习计划，可推送到快捷栏："今日功法·八段锦"

#### 10. 通知预留
- `getPendingReminders()`: 如有练习计划，返回今日待练项目
- 二狗可据此提醒："下午 3 点了，该练八段锦了"

## 特殊说明

- 此模块不依赖 Next API，所有数据本地静态
- 收藏和练习记录使用 DataStore 或 Room 存储
- Tool 实现直接查询 HealthData 对象，无需网络请求
- 未来可考虑从服务器加载更多功法内容（但当前不需要）
