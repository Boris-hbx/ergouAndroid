# 养生功法页面重新设计

## 现状问题

当前布局把所有内容塞在一个平面上，体验混乱：

1. **经络图在每个 tab 都出现** — 八段锦 tab 顶部也放了完整经络图（含14条经络筛选 chip），与功法内容无关，喧宾夺主
2. **信息层级不清** — 打卡统计条、经络筛选控件、经络 Canvas、功法卡片列表全部堆叠，用户不知道重点在哪
3. **没有参考 Next 前端的双模式设计** — Next 前端对「功法模式」和「经络浏览模式」有完全不同的 UI 布局，而 app 全部混在一起
4. **经络图和功法卡片没有联动** — 选中某个八段锦动作时，经络图不会高亮该动作涉及的经络

## 设计参考（Next 前端）

Next 前端的健康模块有清晰的两级导航：

```
Hub 页面（2x2 网格卡片）
  ├── 八段锦 → 功法详情页
  ├── 经络   → 经络浏览页
  ├── 易筋经 → 功法详情页
  └── 站桩   → 功法详情页
```

### 功法详情页布局（八段锦/易筋经/站桩）
```
[← 返回]                    [标题：八段锦]
[横向滚动动作卡片: 预备式 | 第1式 | 第2式 | ...]    ← 选中高亮
[经络人体图 Canvas]                                  ← 只显示当前动作涉及的经络
[正面/背面 切换]
[教学视频播放器]                                     ← 可选
[详情面板: 名称 + 描述 + 功效 + 涉及经络 + 重点穴位]
```

### 经络浏览页布局
```
[← 返回]                    [经络图]
[横向滚动经络列表: 肺经 | 大肠经 | ...]              ← 带颜色圆点+脏腑名
[经络人体图 Canvas]                                  ← 只显示选中的经络
[正面/背面 切换]
[详情面板: 经络名 + 描述 + 属性 + 穴位列表(可点击)]
```

## 新设计方案

### 页面结构

保留 Tab 导航（八段锦 | 易筋经 | 站桩 | 经络穴位），但每个 tab 的内容布局完全不同。

---

### A. 功法 Tab（八段锦 / 易筋经 / 站桩）

整页从上到下一个 LazyColumn：

```
┌─────────────────────────────┐
│  [横向滚动动作卡片]           │ ← 固定在 tab 下方，不跟随滚动
│  预备式 | 第1式 | 第2式 | ... │
└─────────────────────────────┘
┌─────────────────────────────┐
│                             │
│   经络人体图 Canvas          │ ← 3:4 比例
│   (只显示当前动作涉及的经络)  │
│                             │
│         [正面 | 背面]        │
└─────────────────────────────┘
┌─────────────────────────────┐
│  ▶ 观看演示视频              │ ← 可展开的内嵌播放器
└─────────────────────────────┘
┌─────────────────────────────┐
│  动作名称                    │
│  动作描述                    │
│                             │
│  功效                       │
│  · 功效1                    │
│  · 功效2                    │
│                             │
│  经络刺激                    │
│  ● 三焦经 — 主要刺激        │
│  ○ 肺经 — 次要刺激          │
│                             │
│  要领（站桩特有）             │
│  ┌ 意念: ... ┐              │
│  └ 呼吸: ... ┘              │
└─────────────────────────────┘
┌─────────────────────────────┐
│  打卡统计  🔥3天 今日2/10    │ ← 移到底部，不抢视觉焦点
│  [✓ 打卡] [★ 收藏]          │
└─────────────────────────────┘
```

**关键交互：**
- 横向动作卡片选择 → 经络图自动切换到该动作涉及的经络（高亮主/次经络）
- 经络图上的穴位可点击查看详情
- 打卡/收藏针对当前选中的动作

---

### B. 经络穴位 Tab

```
┌─────────────────────────────┐
│  [横向滚动经络列表]           │ ← 固定在 tab 下方
│  ●肺经 ●大肠经 ●胃经 ...    │ ← 单选，带颜色圆点+脏腑名
└─────────────────────────────┘
┌─────────────────────────────┐
│                             │
│   经络人体图 Canvas          │ ← 3:4 比例
│   (只显示选中的那条经络)      │
│                             │
│         [正面 | 背面]        │
└─────────────────────────────┘
┌─────────────────────────────┐
│  手太阴肺经                  │
│  Lung Meridian              │
│                             │
│  描述...                    │
│                             │
│  基本属性                    │
│  五行: 金 | 阴阳: 阴 | 脏腑: 肺│
│                             │
│  主要穴位 (5)                │
│  [中府] [尺泽] [列缺] ...   │ ← 可点击，点击后经络图高亮该穴位
│                             │
│  穴位详情（选中时显示）       │
│  中府 (LU-1) Zhōng Fǔ      │
│  功效: 宣肺理气...           │
│  主治: 咳嗽、气喘...         │
└─────────────────────────────┘
```

**关键交互：**
- 经络列表单选 → Canvas 只显示这一条经络 + 其穴位
- 穴位标签可点击 ↔ Canvas 上穴位可点击（双向联动）
- 正/背面切换保留

---

### C. 去掉的元素

| 去掉 | 原因 |
|------|------|
| 每个 tab 都显示14条经络筛选 chip | 功法 tab 不需要手动选经络，应自动根据动作关联 |
| 顶部打卡统计条 | 视觉干扰，移到功法详情底部 |
| 功法 tab 里的卡片列表 | 改为横向滚动卡片选择器 |
| CategoryIntroCard | 功法介绍文字合并到横向卡片选择器上方或首次使用提示 |
| "全部"筛选 chip | 功法 tab 自动关联，经络 tab 改为单选 |

---

### D. 视觉细节

- 经络图 Canvas 背景与页面背景融合（去掉独立背景色，用透明背景 + 人体轮廓）
- 动作卡片选中态：底部彩色下划线 + 字体加粗
- 经络列表选中态：背景色 + 左侧彩色竖条
- 穴位选中时 Canvas 上放大 + 白色光环，底部面板滑出详情

---

## 实现计划

### Phase 1: 功法 Tab 重构
1. 新建 `ExerciseDetailView` — 横向动作选择 + 经络图联动 + 详情面板
2. HealthViewModel 添加 `selectedExerciseId` 状态
3. 选中动作时自动设置 `selectedMeridianIds` 为该动作的 `stimulatedMeridians`
4. 打卡/收藏 UI 移到详情底部

### Phase 2: 经络穴位 Tab 重构
1. 经络列表改为单选模式
2. 穴位标签与 Canvas 双向联动
3. 经络详情面板（属性 + 穴位列表 + 穴位详情）

### Phase 3: 打磨
1. 动画过渡（切换动作/经络时的 Canvas 过渡）
2. 搜索适配新布局
3. 去掉冗余 UI 元素
