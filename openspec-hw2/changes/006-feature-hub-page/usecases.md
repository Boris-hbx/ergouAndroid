## Use Cases

### Use Case: Browse all features

**Primary Actor:** User
**Scope:** Ergou App
**Level:** User goal

**Preconditions:**
- User is on the chat main screen

**Success Guarantee (Postconditions):**
- User sees all available feature modules in a grid layout

**Trigger:** User taps the hamburger menu button (top-left)

**Main Success Scenario:**
1. User taps the hamburger menu icon in the top-left corner of ChatScreen
2. System navigates to the Feature Hub page
3. User sees a grid of feature cards (任务/习惯/回顾/记账/差旅/学习/养生)
4. User taps a feature card
5. System navigates to the selected feature's page

**Extensions:**
- 3a. User taps the back button: System returns to ChatScreen
