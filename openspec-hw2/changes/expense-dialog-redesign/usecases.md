## Actors

- **用户**: 使用记账功能的人
- **二狗 AI**: 分析票据、生成描述的 AI 助手

## Use Cases

### UC-1: 新建空白账单

**触发**: 用户点击 "+" 新增按钮

**流程**:
1. 系统弹出记账 Dialog
2. 用户填写标题
3. 用户输入金额，选择币种（同行显示）
4. 用户选择日期，可选设置票据时间（精确到时分）
5. 用户可选填写描述（可折叠文本框）
6. 用户可选添加票据照片
7. 用户点击"让二狗分析"或"保存"

**结果**: 账单创建成功，Dialog 关闭，列表刷新

### UC-2: 让二狗分析票据

**触发**: 用户在任意 Dialog 状态点击"让二狗分析"

**流程**:
1. 系统将当前已填信息（标题/描述/照片）发送给 AI
2. AI 分析后回填：标题、金额、币种、票据时间、明细列表、描述摘要
3. 明细双语显示：原始语言 + 翻译（中文票据→英文翻译，英文票据→中文翻译）
4. 描述字段填充 AI 生成的概述
5. 用户可修改任意 AI 填充的字段
6. 用户点击"保存"

**结果**: AI 分析结果回填到 Dialog 各字段

### UC-3: 编辑已有账单

**触发**: 用户在列表点击某条账单

**流程**:
1. 系统弹出编辑 Dialog，预填已有数据
2. 标题、金额+币种、日期/时间、明细、描述、照片均可编辑
3. 用户可点击"让二狗分析"重新分析（二次分析）
4. 用户修改后点击"保存"或"删除"

**结果**: 账单更新/删除成功，Dialog 关闭，列表刷新

### UC-4: 描述折叠展开

**触发**: 描述内容超过2行

**流程**:
1. 描述默认显示2行，无滚动条，超出部分隐藏
2. 用户点击"展开"查看完整描述
3. 用户点击"收起"恢复2行显示
4. 展开状态下可编辑全部内容

**结果**: 描述在折叠/展开状态间切换

### UC-5: 明细双语显示

**触发**: AI 分析完成后，明细包含双语信息

**流程**:
1. 每个明细项显示原始文本 + tag 标识（"原始"）
2. 下方显示翻译文本 + tag 标识（"中文翻译"/"英文翻译"）
3. 右侧显示数量和金额

**结果**: 用户可看到每个明细的原始和翻译版本
