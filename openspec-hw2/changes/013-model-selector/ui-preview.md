## 点击「对话模型」→ 弹出选择对话框

样式与「选择主题」对话框一致（RadioButton 列表）：

```
┌──────────────────────────────────────┐
│  选择对话模型                         │
│                                      │
│  ◉  DeepSeek deepseek-chat          │
│     ✓ API Key 已设置                 │
│                                      │
│  ○  Claude claude-opus-4-6          │
│     ✓ API Key 已设置                 │
│                                      │
│                                      │
└──────────────────────────────────────┘
```

如果某个模型的 API Key 未设置，显示警告：

```
┌──────────────────────────────────────┐
│  选择对话模型                         │
│                                      │
│  ◉  DeepSeek deepseek-chat          │
│     ✓ API Key 已设置                 │
│                                      │
│  ○  Claude claude-opus-4-6          │
│     ⚠ API Key 未设置                │
│                                      │
│                                      │
└──────────────────────────────────────┘
```

> 未设置 Key 的模型仍可点选，但选择后会自动弹出对应的 API Key 设置对话框。

## 设计要点

1. **SettingsItem 复用** — 和主题、API Key 等现有条目完全一致的行布局
2. **Dialog 复用** — 和 `ThemeModeDialog` 同样的 RadioButton 列表风格
3. **副标题格式** — `{厂商} {模型型号}`，如 `DeepSeek deepseek-chat`、`Claude claude-opus-4-6`
4. **API Key 状态提示** — 每个选项下方一行小字，绿色 ✓ 或橙色 ⚠
5. **选中即生效** — 点击 RadioButton 直接切换，无需确认按钮（同主题选择行为）
