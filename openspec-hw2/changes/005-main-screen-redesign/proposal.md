## Why

当前二狗主界面就是 ChatScreen，功能入口藏在侧边抽屉里，用户需要点击菜单才能看到任务/习惯/记账等功能卡片。这与设计参考文档 3.2 章节确定的方向不符——快捷条应该直接显示在输入框上方，让用户一眼看到常用功能、一键跳转。同时顶栏、空态欢迎、输入框等细节也需要对齐设计稿。

## What Changes

- **新增快捷条组件**：输入框上方增加横向滚动的快捷标签条，显示最近/常用条目（如 `[Todo]例行` `[记账]差旅`），点击跳转对应功能页
- **重构顶栏**：左侧显示"二狗"标题，右侧放 [历史] 和 [设置] 按钮，移除现有的抽屉菜单按钮
- **会话历史入口改造**：从侧边抽屉改为独立的历史会话页面（或底部弹出面板），从顶栏 [历史] 按钮进入
- **优化新会话空态**：空对话时显示二狗问候语 + 2-3 个建议话题卡片
- **移除侧边抽屉**：功能入口迁移到快捷条后，侧边抽屉不再需要

## Capabilities

### New Capabilities
- `shortcut-bar`：输入框上方的快捷标签条，横向滚动显示常用功能条目，支持按使用频率/时间自动排序
- `session-history-page`：独立的会话历史页面，替代现有侧边抽屉中的会话列表，支持新建/切换/删除会话
- `empty-state-welcome`：新会话空态设计，包含二狗问候语和建议话题卡片

### Modified Capabilities
（无现有 spec 需要修改）

## Impact

- **UI 层**：`ChatScreen.kt` 主要改动（顶栏、快捷条、空态、移除抽屉），新增 `SessionHistoryScreen.kt`
- **导航**：`ErgouNavigation.kt` 新增会话历史路由
- **ViewModel**：`ChatViewModel` 需要暴露快捷条数据（常用功能列表）；可能需要新的 `SessionHistoryViewModel`
- **数据层**：快捷条排序可能需要记录功能使用频率（DataStore 或 Room）
- **无 breaking change**：纯 UI 层改造，不影响数据层和 API 层
