## 组件拆解

### 1. TopAppBar

```
┌──────────────────────────────────────────┐
│  ←  记账       [日][周][月]         📊   │
└──────────────────────────────────────────┘
```

- **← 返回按钮**: `navigationIcon`, 返回上级 (Hub)
- **标题**: "记账", 粗体
- **时间粒度切换**: `SegmentedButton` 或自定义 `TabRow`, 三档: 日 / 周 / 月
- **图表按钮**: `IconButton(BarChart)`, 预留入口 (本次不实现功能)

### 2. 时间窗导航器

```
           ◀  2026年3月  ▶
```

- 左右箭头切换时间窗
- 显示内容跟随 TopAppBar 中选择的粒度:
  - **日**: `3月8日 周六`
  - **周**: `3月3日 - 3月9日`
  - **月**: `2026年3月`

### 3. 总额摘要 (单行)

```
  总支出  CA$202.22
```

- 不用卡片, 单行文本即可, 省空间
- 左侧 "总支出" 灰色小字, 右侧金额加粗
- 显示**当前时间窗 + 分类筛选后**的合计金额
  - 选了"月" + "超市" → 显示本月超市总支出
  - 选了"周" + "全部" → 显示本周全部总支出

### 4. 分类筛选 Chips

```
(全部) (娱乐) (加油) (超市) (餐饮) (交通) (机场) ···
```

- `LazyRow` 横向滚动
- `FilterChip`, 选中高亮
- 第一个固定为 "全部"
- 分类从已有账单中动态提取
- 选中某分类后, 列表和总额同步过滤

### 5. 按日期分组的账单列表

```
昨天 · CA$6.00                      ← 日期分组 header (日期 + 小计)
┌────────────────────────────────┐
│  Royal Botanical Gardens – ... │
│  [娱乐]            📷 CA$6.00 │   ← 账单条目
└────────────────────────────────┘
```

- **分组 Header**: 日期 (今天/昨天/具体日期) + 当日小计金额
- **账单条目 Card**:
  - 左侧: 商户名 (单行, 过长省略) + 分类标签 (chip)
  - 右侧: 收据图标 (有图片时显示) + 金额
- 点击条目 → 进入编辑/详情
- 左滑删除 (保留现有 SwipeToDismiss)

### 6. FAB 添加按钮

```
                                    ⊕
```

- 右下角浮动 `FloatingActionButton`
- 点击打开添加账单 dialog (保留现有逻辑)

## 与现有页面的差异

| 现有 | 目标 |
|------|------|
| TabRow 切月份 | SegmentedButton 切日/周/月 + 箭头导航时间窗 |
| 饼图在顶部 | 去掉饼图, 改为单行总额 |
| 平铺列表无分组 | 按日期分组 + 小计 header |
| 无分类筛选 | 横向 FilterChip 筛选 |
| 条目显示简单 | 条目加收据图标 + 分类tag |

## 不改动的部分

- 添加/编辑账单 Dialog (保留现有)
- SwipeToDismiss 删除
- Snackbar 撤销
- 数据层 (NextApiService, ViewModel 核心逻辑)
- 收据图片上传/展示
